# Star Wars ASCII 3DS

## Description

Watch Star Wars ASCII natively on a jailbroken Nintendo 3DS

## Setup

Copy the ‘starwarsascii3ds.3dsx’ file onto the microSD card of your jailbroken 3DS within the ‘3ds’ directory. Then put the micro SD back into your 3DS and open the 'Homebrew' app. You should then have the option to launch the 'Star Wars ASCII 3DS' app.
